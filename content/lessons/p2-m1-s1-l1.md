# De dónde salen las imágenes

Un modelo de visión no aprende agronomía: aprende a separar lo que vio en sus datos de entrenamiento. Por eso la primera pregunta de CropEye no fue qué arquitectura usar, sino de dónde obtener imágenes representativas de tomate y papa enfermos. La respuesta fue un conjunto heterogéneo de seis fuentes, con licencias distintas y calidades muy dispares.

## Seis fuentes, tres regímenes legales

Las fuentes combinan conjuntos públicos de referencia con recortes de campo. Entre las que aparecen documentadas están PlantVillage, con imágenes de laboratorio sobre fondo uniforme; PlantDoc, con fotografías tomadas de la web en condiciones variadas; y recortes de campo de Pakistán y Tanzania. A ellas se suma `a5_tomato_village`, la única sin licencia declarada.

```text
Licencia                Qué permite                          Qué complica
CC BY 4.0               usar, adaptar y compartir citando     exige atribución
CC BY-NC-ND 4.0         usar sin fines comerciales            prohíbe obras derivadas
Sin licencia declarada  nada de forma explícita              todo uso es ambiguo
```

La licencia CC BY-NC-ND es la más incómoda para un proyecto de visión artificial. Prohíbe los usos comerciales y las obras derivadas, y entrenar un modelo con esas imágenes es, como mínimo, una zona gris: el modelo no copia píxeles, pero aprende de ellos. La fuente sin licencia declarada es peor todavía, porque la ausencia de licencia no significa libertad: significa que no hay permiso explícito.

:::warning
Antes de publicar un modelo entrenado con datos de terceros conviene revisar cada licencia con alguien que sepa de propiedad intelectual. Este curso describe lo que el proyecto hizo; no constituye asesoría legal.
:::

## El set sellado de 801 fotos

El proyecto reservó 801 fotografías de campo como conjunto de prueba final. «Sellado» significa que no se usaron para entrenar, ajustar hiperparámetros ni elegir la versión del modelo. Si se miraran durante el desarrollo, el equipo tomaría decisiones que mejoran ese conjunto en particular y la evaluación dejaría de medir generalización.

Ese set es el número más honesto del proyecto. Las métricas de laboratorio pueden llegar a 0,950 o 0,995; sobre las 801 fotos de campo, la versión 4 obtuvo F1 de 0,908 y exactitud de 0,945. La diferencia entre ambos mundos no es un defecto del modelo: es la medida del salto entre el laboratorio y el invernadero.

## Datos que no se parecen al campo

PlantVillage muestra hojas recortadas sobre fondos limpios. Una foto tomada con un teléfono en un invernadero tiene sombras, otras hojas, tierra, malla y reflejos. Cuando el conjunto de entrenamiento y el de uso no comparten esa distribución, el modelo aprende atajos: el color del fondo, la forma del recorte, la iluminación. Y esos atajos no existen en producción.

La tensión es inevitable: los datos de laboratorio son abundantes y están etiquetados; los de campo son escasos, caros y ruidosos. CropEye eligió combinar ambos, aceptando que cada fuente aporta un sesgo distinto.
